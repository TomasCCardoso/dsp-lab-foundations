# DSP Lab Foundations

Applied DSP fundamentals: filter design, spectral analysis, and 
signal processing tooling built from scratch. Python/NumPy/SciPy.

Part of a long-term technical mentorship program in RF/Telecommunications 
engineering, structured as progressive applied projects.

## Structure
- `src/` — core DSP implementations
- `tests/` — unit tests
- `notebooks/` — exploratory analysis
- `docs/` — technical notes and design decisions
